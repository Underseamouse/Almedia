Тестовое задание: редизайн мобильного приложения Freecash с фокусом на
onboarding flow.

**→ [Живой прототип](https://underseamouse.github.io/Almedia/)** — кликается
насквозь, от загрузки до разблокированных офферов.

> Учебная работа. Бренд Freecash, логотипы и арт игр принадлежат
> правообладателям и используются только для показа дизайн-решения,
> без коммерческой цели.

## Прототип

Полный онбординг-флоу, собранный по макетам и сверенный замерами в кадре
402×874:

```
загрузка → интро → 4 карточки (match-3, стрик, выплаты, подарок)
        → регистрация → офферы → опросник в шторке → офферы разблокированы
```

Запуск и сборка — в [prototype/README.md](prototype/README.md). Там же
разобраны решения по анимации и три ловушки, на которых стоило споткнуться
один раз, а не трижды.

Публикуется через GitHub Pages из папки `docs/` (Settings → Pages →
Deploy from a branch → `main` / `/docs`). Обновить:

```bash
cd prototype && npm run deploy
```

## Принцип

Каждое решение здесь идёт вместе с «почему». Правило говорит что делать,
принцип — ради чего. Отклонения от дизайн-системы фиксируются с причиной,
а не молча.
